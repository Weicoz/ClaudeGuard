# ClaudeGuard 对抗性审查与修复

日期：2026-11-05。基线：`e1c8f57`。范围：Apple Silicon 原生守护、共享准入策略、CLI/桌面启动入口、Claude-W 集成、root 网络助手和安装/卸载/打包。假设：一位本机用户，多个并发启动入口；配置、外部响应、磁盘和子进程均可失败。root 或本机账户已被完全控制不属于防护边界。

源码审查和隔离验证已完成；本机运行版本、生产防火墙和公开 Release 未替换。通过只表示本轮已识别的问题均已修复并通过对应检查，不表示穷尽未来故障。

## 已修复

| 编号 | 反例与影响 | 修复和验证 |

| A04 | 全局 PF 加载、停用和连接清空影响其他软件 | 专属锚点、PF 引用令牌、启动会话核对；仅清理目标地址连接。模拟命令核对，生产内核未验证 |
| A05 | root 接受用户准备的完整 hosts/PF 文件；并发暂存互相覆盖 | 串行单次结构化请求，限制字段、域名、IP、文件类型/所有者/大小；root 从当前 hosts 合并，仅改自己的区段 |

| A11 | 配置成为 FIFO 会卡住守护；损坏配置可触发无界限立即重检 | 非阻塞普通文件读取、大小限制、保留无效字节指纹；真实 Swift 反例 |

## 迭代与证据

先加入失效反例，再修复并全量复验。首轮证明类型绕过、未来时间、FIFO 阻塞、hosts 截断与风险失败缓存。后续复审发现并修复别名恢复顺序、hosts 空行残留、异常分支误放行和配置重检循环；任何一轮失败均未作为通过交付。

单元测试：132 项，130 项通过，2 项跳过（Tk 未安装、Windows 注册表不适用于本机）。真实 Swift 编译运行、root 命令模拟、loopback HTTP、配置/状态故障与磁盘故障均包含。源代码未新增第三方依赖。性能最终样本：60 秒，CPU 合计 0.2396%，physical footprint 5.359 MB、峰值 5.457 MB；RSS 17.924–19.120 MB。预热后无策略/助手进程，26 次有效探测，结果见 `performance-results.json`。

## 验收边界

内存仍使用 macOS physical footprint、十进制 MB。RSS、短时 Python/root 助手、设置窗口、警告界面和活跃 CLI 包装器另计，不能把空闲结果当作所有瞬时进程的峰值。

未验证：新助手的生产 PF 端到端、其他防火墙共存、旧全局规则迁移、设置手工交互、真实 Desktop/Claude Code 关闭、真实额度/模型请求、全新系统安装、跨平台内核执行及 Thread Sanitizer。没有为验收关闭用户会话、改变 TUN/代理、执行真实模型调用或修改生产 PF。

原性能审查的 R01、R09–R13、R15–R20、R22 等资源/覆盖率建议仍是独立优化候选。它们不能冒充本轮已修复，详情见 `performance-audit.md`；本轮范围内未发现尚未处理的确定性准入绕过或数据损坏问题。

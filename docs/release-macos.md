# macOS DMG 发行

`0.1.0-beta.5` 安装包同时包含直连防火墙菜单和仅阻断网络模式：复检、策略拒绝或系统执行失败不会自动终止已有桌面端与 CLI；新启动仍需通过检查。安装器备份并迁移网络开关，停用旧包装器的自动杀进程监控，保留现有会话。显式终止命令保持独立。

`0.1.0-beta.4` 源码加入可选直连防火墙：设置菜单可以安装、卸载并检查专属 PF 规则，默认不安装。范围与验证边界见 [直连防火墙](direct-firewall.md)。构建新 DMG 不代表已发布 GitHub Release 或替换本机安装。

当前源码只构建 Apple Silicon（arm64），最低 macOS 13。Intel 不在支持范围。

```bash
python3 scripts/build-dmg.py --version 0.1.0-beta.5
```

输出位于 `dist/`：arm64 DMG 和 `SHA256SUMS`。镜像包含预编译程序、运行源码、图标、许可证、卸载脚本、安装入口和逐文件清单，不包含本机配置、凭据或请求历史。当前发行版本为 `v0.1.0-beta.3`；`v0.1.0-beta.1` 不包含本轮修复。此前的 `audit.1` 仅是本地审查候选。

用户打开镜像，双击 `Install ClaudeGuard.command`。它先核对清单，再运行安装器；网络助手需要管理员权限，由用户输入密码。需要可用的 `/usr/bin/python3`。自动请求默认禁用；已有计划与启用状态保留。后台守护独立运行，菜单栏图标常驻显示；关闭菜单不退出图标。菜单栏与后台合计资源需要重新测量，先前无界面守护低于 10 MB 的样本不能代表合计占用。

本轮网络协议已升级。用户进程只提交结构化请求；root 助手检查文件类型、所有者、大小及输入格式，只操作 `com.apple/claudeguard` 锚点，并返回带请求号的回执。解除拦截只释放当前启动会话中本程序持有的 PF 引用。卸载不关闭全局 PF、不清空全局连接、不删除用户配置与历史。

安装前必须存在能够执行专属锚点的主规则入口，例如 macOS 默认的 `anchor "com.apple/*"`。若系统只装载旧版全局 `to <claude_guard>` 规则，或没有锚点入口，安装器在替换文件前停止。管理员必须先核对当前 PF、其他网络软件和原有主规则，再制定迁移；不得直接用全局重载覆盖未知规则。源码构建和预编译签名核对也在停止原守护前完成。中途系统安装失败会返回错误，必须检查安装状态后恢复或重试。

这是安装器型 DMG。本地 ad-hoc 签名不等于 Developer ID 签名、Gatekeeper 验收或 Apple 公证。下载后的系统安全检查可以阻止运行，不得关闭安全保护来绕过。

已验证范围见 [对抗性审查](adversarial-review.md)。未验证：新协议在生产 PF 上的真实应用、旧全局规则迁移、设置菜单手工交互和全新系统完整安装。源码审查结束时，本机安装尚未替换；本机更新必须独立核对安装版本、系统助手回执与运行状态，不得从 Release 状态推定安装成功。
